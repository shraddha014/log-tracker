# Antigravity Knowledge Base & Project Rules

## Core Collaboration Protocol
- **Always Check First Before Action**: Before executing any code changes, creating or editing files, running state-modifying terminal commands, or making git commits/pushes, ALWAYS explain the proposed plan and approach to the user first and wait for explicit confirmation/approval.
- **Explicit Confirmation Required**: Never apply code edits or commit/push changes automatically without the user's prior review and go-ahead.
- **Inquire and Confirm Intent**: When requirements are discussed or new features are requested, outline the solution and ask the user for feedback/approval before taking action.
